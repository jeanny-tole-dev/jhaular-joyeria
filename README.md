# 💎 Jhaular Joyería — Plataforma E-Commerce & Laboratorio 3D

Plataforma e-commerce interactiva desarrollada para joyería artesanal en esmeraldas. Incorpora catálogo dinámico de productos, panel de administración con control por roles (Cliente, Empleado, Administrador) y laboratorio 3D interactivo desarrollado con Three.js para la personalización de manillas tridimensionales en tiempo real.

## 🚀 Características Principales

- 💎 **Laboratorio 3D Interactivo (Three.js & WebGL)**: Personalizador visual de manillas tridimensionales en tiempo real.
- 🔐 **Gestión de Usuarios & Roles**: Autenticación segura mediante Supabase Auth con niveles de acceso para Clientes y Administradores.
- 📦 **Catálogo Dinámico & Carrito**: Filtrado por materiales, piedras preciosas (esmeraldas) y cotización instantánea.
- 📱 **Diseño Responsivo**: Adaptado para experiencia de compra fluida en móviles y escritorios.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Zustand (Estado global).
- **Experiencia 3D**: Three.js, WebGL.
- **Backend & DB**: Supabase (PostgreSQL, Auth, Realtime).
